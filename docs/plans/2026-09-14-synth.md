## Context

Four decisions recorded in CLAUDE.md are waiting on data Abt-Buy cannot supply:

| decision | why Abt-Buy can't settle it |
| --- | --- |
| 20 : 2 : 1 cost ratio | calibrated scores are bimodal: 64 of 18,819 test candidates fall between 0.01 and 0.95 |
| Platt over isotonic | isotonic lost for lack of positives (230 held out, 777 out of fold) |
| blockers with zero marginal completeness (LSH tested with token shingles only) | 2,173 pre-blocked records, and no token-drop corruption |
| unemitted pairs priced at p = 0 in `cluster/` | entity sizes are only 2 and 3 |

`service/` would lock all four in, so `synth/` comes first. Choices already made:

- **Seed source:** products derived from Abt-Buy's **train split**.
- **Milestone scope:** the generator, plus mid-scale runs.
  - The model and cluster reports run on a catalog of about 20k records, small enough for `ann`'s dense index.
  - The blocking table alone runs at 200k, with SVD passed to `ann` explicitly.
  - The default blocker set and every committed Abt-Buy report stay byte-identical.

## Design

### 1. Where the code lives

The registry rule is enforced by `tests/test_data_registry.py`: no module outside `data/` may import a loader.

- **`src/dedup/synth/`** is dataset-agnostic. `Record`s with `entity_id` go in, synthetic `Record`s come out. It never imports a loader.
  - Its generation CLI resolves the seed dataset through `dedup.data.load_dataset`, which is allowed, the same way the other CLIs do.
- **`src/dedup/data/synthetic.py`** loads a materialized catalog. Its registry entries are `synth-20k` and `synth-200k`, with default roots under `data/synth/` (gitignored).
- **Format: `records.jsonl` plus `manifest.json`.**
  - JSONL, not CSV, because CSV collapses None and `""`, the distinction `features/missingness.py` keys off.
  - The manifest records the generator config, seed dataset, seed split parameters, counts, and a SHA-256 of `records.jsonl`.

### 2. Leakage (invariant I1)

- **Seeds come from the train split only.** They are `split_by_entity(seed records, test_fraction=0.3, seed=0)[0]`, and the manifest records the split parameters. Abt-Buy's test split never reaches the generator.
- **New optional field `Record.split_group: str | None = None`.**
  - `split_by_entity` and `kfold_by_entity` group on `split_group or entity_id`, and raise if one entity's records carry different groups.
  - Synthetic records set it to the seed-family id. Every sibling and duplicate derived from one seed then lands on one side of every split and fold, so no test entity is scored against training siblings built from the same seed text.
  - Abt-Buy leaves it `None`. The partition is then unchanged, and the gated published-number tests plus byte-identical report regeneration prove it.
- **Why a schema field rather than `raw_attributes`:** that field's contract is "no pipeline stage reads this". A first-class field is explicit, and every split call site inherits it: `eval/baseline.py`, `features/`, `model/` and `cluster/evaluate.py`, plus `model/calibrate.py`.

### 3. The generator

**`synth/families.py`: distinct products from one seed.** The root product is one base listing per seed (prefer a record with a model code; ties break on `record_id`). Siblings come in two kinds:

- **Near siblings:** vendor code at edit distance 1–2. Mutations:
  - change a digit in the last digit run
  - swap a colour or region suffix, changing the title's colour word with it (`WF`↔`BF`)
  - bump a version (`9763A001`→`9764A001`)
  - optionally change a size or capacity number
- **Far siblings:** a fresh code of the same shape, keeping the same brand and category words.

Distinctness is guaranteed, not hoped for:
- no two entities in the catalog share a `normalize.code_key`
- no two entities share a normalized base title

Seeds with no code get size and colour siblings only.

**`synth/corrupt.py`: duplicates of one product.** Pure operators, each `(fields, rng) -> fields`:
- typos (insert, delete, substitute, transpose)
- abbreviation
- token drop and token reorder, including moving the code to the front
- unit spellings, both ones `normalize` absorbs and ones it doesn't (`32-inch`)
- code punctuation (`KXTS208W`↔`KX-TS208W`)
- region-suffix append (`/XAA`)
- code dropped, and an alternate identifier. Each entity gets a second code from a different scheme, giving the 20% of pairs where both codes are present but differ.
- price jitter and price removal
- brand alias, brand None, brand `""`
- description truncation or emptying

No operator may produce a blank title.

**`synth/generate.py`: orchestration.**
- `SynthConfig` (frozen) holds:
  - target record count
  - entity-size distribution: singletons plus a tail up to 8
  - near/far sibling mix
  - corruption profile
  - seed
- Each family draws from its own RNG, seeded from a `hashlib` digest of `(seed, entity_id)`, never Python's `hash()`. Adding or removing one seed then cannot change any other family's output.
- Record ids take the form `synthetic:<family>:<entity>:<n>`, with `source="synthetic"`.
- `raw_attributes` carries lineage: the seed `record_id` and the operators applied.

**Default entity-size distribution.** About 40% singletons, 30% twos, 15% threes, and 15% sizes 4–8.
- This is a judgment call, since no measurement grounds it, and it gets recorded as an open question.
- The tail beyond three is required, or the p = 0 under-merge question stays untestable.

**`synth/realism.py`.** `pair_statistics(records)` is dataset-agnostic and computes the table above: token Jaccard quantiles, code agreement categories, price presence and gap, entity sizes, sibling rate. The same function runs on the seeds and on the output.

**Calibration.** Tune the corruption defaults by hand against **Abt-Buy train** statistics, never test, until they land within tolerance:
- Jaccard mean within ±0.05
- each code category within ±0.05
- price gap median within ±0.05

**Two deviations, stated in the report and not tuned away:**
- **Sibling rate** will exceed the real 0.56 at scale by construction. The far-sibling share is the only knob.
- **No two-sided structure.** Brand presence is independent per record, so quirks like `desc_len_ratio` pointing backwards will not reproduce.

**CLI.**
```
python -m dedup.synth.generate --seed-dataset abt-buy --records 20000 --seed 0 \
    --out data/synth/abt-buy-train-20k --report reports/synth/realism.md
```

### 4. Making the reports dataset-neutral (prerequisite for the runs)

Three renderers print Abt-Buy facts regardless of `--dataset`:

- **`blocking/evaluate.py`:** the "Abt-Buy is pre-blocked" bullet, and the tuned-on-this-catalog bullet with 0.9949 / 1.0000.
- **`features/evaluate.py`:** the wrong-way paragraph ("Buy against Buy", 249 vs 34 characters), and "`brand_equal` can address 8 of 341".
- **`model/evaluate.py`:** the `BASELINE_*` constants, always rendered, and the `desc_len_ratio` note saying "on Abt-Buy".

**Fix:** `DatasetSpec` gains `notes: DatasetNotes`, a frozen dataclass with four fields:
- blocking bullets
- features paragraphs
- gain-column explanations (column → sentence)
- `baseline_report: Path | None`

Renderers print what the CLI hands them and never branch on a name.
- **Abt-Buy:** its entry carries the **exact current text**, so all committed reports regenerate byte-identically.
- **Synthetic:** its entries carry their own caveats. For example, parameters were tuned on Abt-Buy, not on this catalog, and sibling density is above real.
- **Baseline row:** `model/evaluate.load_baseline_row(path)` parses it, moving the parsing out of `test_the_restated_baseline_row_matches_the_committed_report`. It refuses a report whose `Dataset:` line names a different dataset. With no baseline, the comparison row is omitted and a sentence says so.
- **Test that pins the overclaim:** `tests/test_blocking_evaluate.py::test_report_states_the_benchmark_is_pre_blocked` asserts that a `dataset="synthetic"` report says "pre-blocked". Replace it with a test that renders the given notes, plus a test that a dataset without notes makes no such claim.

**Blocker set:** add `default_blocker_set(ann_components: int | None = None)` and a `--ann-components` flag on `blocking/evaluate.py`. `None` keeps Abt-Buy's candidate set identical.

### 5. The runs (the milestone deliverable)

1. **Generate:** create `synth-20k` twice and confirm the files are byte-identical. Measure its char-3gram vocabulary against the `ann` budget; if it doesn't fit, lower the size until the default dense path fits.
2. **Realism report:** `reports/synth/realism.md` shows synthetic against Abt-Buy-train statistics, both deviations, and the manifest hash.
3. **Baseline:** `eval.baseline --dataset synth-20k --min-similarity <floor>`. Choose the floor for memory on the train side, and the report states the recall ceiling it costs.
4. **Pipeline:** run the `blocking`, `features`, `model` and `cluster` CLIs on `synth-20k`, writing to `reports/synth/`, and record wall-clock times.
5. **Blocking at scale:** run `blocking.evaluate --dataset synth-200k --ann-components 128`, writing `reports/synth/blocking-200k.md`.

These reports supply evidence; they don't settle anything automatically. Settling any of the four decisions happens after reading them, in CLAUDE.md's Open questions, in the same commit.

## Tests that carry the weight

- **Generator:**
  - the same seed gives byte-identical output
  - removing one seed family leaves every other family's records unchanged
  - every record validates as a `Record`, with `entity_id` and `split_group` set
  - no `record_id` collisions
  - `blocking.union.ground_truth` agrees with `count_true_pairs`
- **Families:** a sibling's code key differs from every other entity's; a near sibling sits at edit distance 1–2; a colour suffix swap changes the title's colour word with it.
- **Corruption:** unit spellings that `normalize` absorbs normalize equal; code punctuation variants share a `code_key`; no operator produces a blank title.
- **Splits:** a family never straddles train and test or two folds; an entity with two groups raises; with no groups, the partition equals today's.
- **Loader:** JSONL round-trips None vs `""`; a missing manifest or a non-synthetic `source` is refused.
- **Reports:** a report for a dataset without notes contains no "pre-blocked", "0.5204" or "Buy against Buy". Abt-Buy's rendering is unchanged.
- **Gated on real data:** synthetic statistics from Abt-Buy train seeds land within the calibration tolerances.
