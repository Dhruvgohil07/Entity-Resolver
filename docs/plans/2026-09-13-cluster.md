### The merge criterion is closed-form, like the bands

A partition decides every pair: same cluster = merge, different = split, and there is no review
action. With calibrated `p`, the expected cost of a partition is
`Σ_in-cluster (1−p)·C_fm + Σ_cross p·C_fs`, where pairs blocking never emitted count as `p = 0`.
Merging clusters A and B therefore lowers expected cost exactly when
**mean p over all |A|·|B| cross pairs > τ = C_fm / (C_fm + C_fs)** (0.9091 at 20 : 2 : 1).
Missing pairs count toward the mean as zeros, so a single bridge between two pairs averages
0.99/4 ≈ 0.25 and cannot merge. Average linkage stopped at τ is the greedy optimizer of this
objective, and correlation clustering is the global one. Both inherit the cost model rather than
adding a new tuning knob, and nothing is fit on test.

## Approach

Branch `feat/cluster` off the current `feat/features` HEAD (stacked: `main` does not have
`model/` yet). Implement in this order, metric before algorithm:

### 1. `src/dedup/cluster/base.py` — the contract (like `blocking/base.py`, `features/base.py`)
- `ScoredGraph(n_records, pair_keys, probabilities)`: a frozen dataclass. Validates that keys are
  sorted, unique and in range for `n` (`blocking/pairs.py` packing), that probabilities are finite
  and in [0, 1] (same message style as `model/threshold.assign_bands`), and that shapes match.
  `edges(min_p)` returns `(left, right, p)` via `blocking.pairs.unpack`. It holds no records and
  no dataset name, so it stays agnostic to both the dataset and the model.
- `canonical_labels(labels)`: relabels so each cluster id is the order of its first record.
  Identical partitions then give identical arrays, which keeps reports reproducible.
- `merge_threshold(cost) -> float` = `C_fm / (C_fm + C_fs)`.
- `expected_partition_cost(labels, graph, cost)`: the objective above. It is computed sparsely:
  in-cluster non-edges are `C(k,2) − in-cluster edges`, never an n×n matrix.

### 2. `src/dedup/cluster/bcubed.py` — the metrics
- `bcubed(predicted, truth) -> BCubedScore(precision, recall, f1, n_records)`, computed from the
  cluster × entity contingency counts. It **requires one label per record in the split**:
  mismatched lengths raise. Isolated records are singletons and count. Scoring only records that
  touch an edge moves the number, the same denominator trap `eval/metrics.py` closes for recall.
- `closure_pair_counts(predicted, truth) -> ClusterPairCounts`: pairs the partition implies,
  true pairs among them, and all true pairs. Properties: precision, recall, and
  `realized_cost(cost)` (false in-cluster pairs × C_fm + split true pairs × C_fs). The recall
  denominator is every true pair in the split, matching `BandSummary`. It sits beside B-cubed
  because the report shows the two disagreeing, which is the point of I6.

### 3. `src/dedup/cluster/components.py` — the baseline, and the failure it demonstrates
- `connected_components(graph, threshold) -> labels`, using `scipy.sparse.csgraph` over edges
  with `p ≥ threshold` (`≥`, the convention `assign_bands` uses).
- `cluster_shapes(labels, graph, threshold)`: per multi-record cluster, its size, edge count and
  **implied pairs** (`C(k,2) − edges`). This is label-free, so the serving path can use it later
  to flag suspicious clusters. The docstring states the chaining failure plainly.
- Add `scipy` to `pyproject.toml` dependencies. It is already installed as a hard dependency of
  scikit-learn, but it is now imported directly.

### 4. `src/dedup/cluster/agglomerative.py` — the greedy fix
- `average_linkage(graph, cost) -> labels`. Starts from singletons over edges with `p > 0`. A heap
  of adjacent cluster pairs is keyed on mean cross p (sum of edge p / (|A|·|B|), missing pairs
  = 0), with lazy invalidation and deterministic tie-breaking on cluster ids. Merging stops when
  the best mean ≤ τ. Adjacency is a dict of sums, and nothing dense is built.

### 5. `src/dedup/cluster/correlation.py` — the global optimizer of the same objective
- `correlation_clusters(graph, cost, *, n_restarts=8, seed=0, max_sweeps=50) -> labels`.
  1. **Pivot phase** (KwikCluster): nodes are taken in a seeded random order, and each pivot
     claims its unclustered neighbours with `p > τ`.
  2. **Local search**: each record moves to whichever neighbouring cluster, or a new singleton,
     maximizes `Σ_{u∈X} ((C_fm+C_fs)·p_uv − C_fm)`. This repeats until no move improves the
     objective or `max_sweeps` is reached.
  3. **Restarts**: the lowest `expected_partition_cost` wins, and ties go to the lowest seed.
     Selecting by that cost uses no labels, so it is not a leak.

### 6. `src/dedup/cluster/evaluate.py` + `reports/cluster.md` — CLI
`python -m dedup.cluster.evaluate --dataset abt-buy --out reports/cluster.md`, with the same
flags as `model/evaluate.py` (`--test-fraction --seed --folds --cost-* --semantic --out`).
- Pipeline in-process, importing no CLI module: `split_by_entity` →
  `model.calibrate.fit_calibrated_scorer(train)` → `model.train.prepare(test)` →
  `scorer.probabilities` → `ScoredGraph`. The best-F1 threshold is re-derived from the OOF scores
  exactly as `model/evaluate.py:220-227` does (3 lines, inlined rather than imported from a CLI).
- **Methods table.** Rows:
  - singletons (floor)
  - components at `p_hi`
  - components at τ
  - components at `p_lo` (auto-merge + review)
  - components at the OOF best-F1 threshold (chaining demonstration)
  - average linkage at τ
  - correlation clustering
  - components over true candidate edges (ceiling)

  Columns: clusters, largest, fused clusters (> 1 entity), split entities, implied pairs, B³
  P/R/F, closure-pair P/R, expected cost, realized cost.
- **Chaining, shown.** Each fused cluster from components at `p_hi` is listed with its record
  titles and the bad edge probabilities (capped at 10). Next to each one: what average linkage
  and correlation did with it (separated / still fused / split wrongly).
- **"Reading this honestly".** Every bullet is chosen from the measured value, following the
  `model/evaluate._reading_notes` pattern:
  - whether the singleton floor is high;
  - whether the best pairwise F1 threshold beats `p_hi` on B³ F;
  - whether the ceiling binds;
  - whether transitive closure recovered true pairs blocking never emitted (0 on this split);
  - whether remaining fusions have every bad edge ≥ `p_hi`, which makes them a model/features
    problem for `error-analyst` rather than a clustering one.

### Tests (all run without data unless marked)
- `tests/test_cluster_base.py`:
  - graph validation errors;
  - `canonical_labels` is invariant to permutation;
  - **`expected_partition_cost` matches brute force**: sum over all C(n,2) pairs on a small
    random graph.
- `tests/test_cluster_bcubed.py`:
  - perfect partition → 1/1;
  - all-singletons recall = mean 1/|entity|;
  - one big cluster → recall 1;
  - invariant to relabelling;
  - a hand-worked example;
  - `test_every_record_is_scored_including_isolated_ones` (a length mismatch raises);
  - closure counts and realized cost.
- `tests/test_cluster_components.py`:
  - A~B, B~C with A≁C gives one cluster with 1 implied pair (the I9 case);
  - threshold `≥`;
  - isolated records are singletons;
  - empty graph.
- `tests/test_cluster_agglomerative.py`:
  - a bridge between two dense pairs does not merge;
  - a true triangle does merge;
  - **each merge's mean-p > τ ⇔ expected cost falls** (the algebra checked against the
    definition, like `test_bands_are_the_argmin_of_expected_cost`).
- `tests/test_cluster_correlation.py`:
  - the result is a local optimum (no single move lowers cost);
  - it equals the brute-force optimum over all set partitions on the bridge, path and dense
    cases (≤ 7 nodes, Bell(7) = 877);
  - the same seed gives the same labels;
  - cost is never worse than components at τ on random small graphs. That is a checked property,
    not a guarantee, so the test uses fixed seeds.
- `tests/test_cluster_evaluate.py`:
  - a synthetic report exercises every reading-note branch (pattern: `synthetic_report` in
    `tests/test_model_evaluate.py`);
  - **real-data, `skipif` + module-scoped fixture**: components at `p_hi` reproduce B³ P 0.9880,
    R 0.9054, 4 fused clusters, 11 implied pairs; the singleton floor gives R 0.4923; the ceiling
    is 1.0000; at the best-F1 threshold, B³ P < P at `p_hi`.
